# ☀️ SunCart – Summer Essentials Store  

**SunCart** is a modern, summer-themed eCommerce platform where users can explore and purchase seasonal products like sunglasses, summer outfits, skincare, and beach accessories. This project focuses on a seamless user experience, secure authentication, and a vibrant, unique design.

---

## 🔗 Project Links
* **Live Deployment:** https://b13-a8-suncart.vercel.app/
* **GitHub Repository:** https://github.com/sheikh-muzammil2026/B13-A8-suncart

---

## 🚀 Key Features
* **Responsive Design:** Fully optimized for Mobile, Tablet, and Desktop views.
* **Secure Authentication:** Powered by **BetterAuth**, featuring Google Social Login and Email/Password registration.
* **Protected Routes:** Product details are restricted to logged-in users only.
* **Dynamic Product Showcase:** Home page highlights top-rated products and summer-exclusive deals.
* **User Profile Management:** Users can view their data and update their Name and Profile Picture.
* **Interactive UI:** Integrated with Lottie and Animate.css for smooth transitions.

---

## 🛠️ Tech Stack
* **Framework:** Next.js (App Router)
* **Styling:** Tailwind CSS
* **UI Components:** DaisyUI
* **Authentication:** BetterAuth
* **Database/Adapter:** MongoDB (with BetterAuth Adapter)

### 📦 Key NPM Packages
* `better-auth`
* `lucide-react` (Icons)
* `react-toastify` (Notifications)
* `lottie-react` and `animate.css`
